# Sprint 6 - UI тестирование Яндекс.Самокат

## Описание проекта
Автотесты для учебного сервиса «Яндекс.Самокат» с использованием:
- Selenium WebDriver
- Page Object Model
- Allure отчеты
- Параметризация тестов

## Архитектура проекта

- **config.py** - Конфигурация проекта
- **pages/** - Page Object классы
  - `base_page.py` - Базовый класс с общими методами
  - `main_page.py` - Главная страница  
  - `order_page.py` - Страница заказа
- **locators/** - Локаторы элементов
  - `main_page_locators.py` - Локаторы главной страницы
  - `order_page_locators.py` - Локаторы страницы заказа
- **tests/** - Тесты
  - `test_questions.py` - Тесты вопросов о важном
  - `test_order.py` - Тесты заказа самоката
- **data/** - Тестовые данные
  - `test_data.py` - Данные для параметризации
- **conftest.py** - Фикстуры pytest
- **run_tests.py** - Скрипт запуска тестов
- **requirements.txt** - Зависимости проекта

## Запуск тестов

### Установка зависимостей:
```pip install -r requirements.txt```

### Запуск всех тестов:
```python run_tests.py```

### Запуск отдельных тестов:
#### Только вопросы
```pytest tests/test_questions.py -v```

#### Только заказы
```pytest tests/test_order.py -v```

#### С Allure отчетом
```
pytest tests/ -v --alluredir=allure-results
allure serve allure-results
```

## Тестовые сценарии
1. Вопросы о важном
Проверка 8 вопросов с параметризацией

Каждый вопрос открывает соответствующий ответ

2. Заказ самоката
Позитивный сценарий с двумя наборами данных

Две точки входа (верхняя и нижняя кнопки)

Полный флоу заполнения формы

3. Проверка переходов
Логотип Самоката → главная страница

Логотип Яндекса → Дзен в новом окне
